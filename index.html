Road Guardian — Project Overview

Android Application Academic Degree Project

Problem Statement & Purpose

Road Guardian is an Android application developed using Android Studio to help people report road-related problems such as damaged roads and waterlogging. Users can capture a photograph of the affected location and submit the report through the application to the relevant authority. Once the issue is resolved, the user can receive a notification or message confirming the update.

Key Functional Highlights

  • Road Damage Reporting: Structured interface to specify damage type (pothole, crack, blockage).
  • Photo Capture: Direct camera integration to attach verifiable photographic evidence.
  • Waterlogging Alerts: Rapid reporting module dedicated to monsoon and drainage hazards.
  • Authority Forwarding: Routes reports with location coordinates to the relevant municipal authority.
  • Status Notifications: Keeps the citizen updated when the reported road issue has been inspected or resolved.

Workflow Steps Implemented

SQL Data Analysis — Template Overview

Database & SQL Customizable Template

Overview

A data analysis project using MySQL to explore structured datasets, summarize information, apply joins and aggregations, and answer analytical questions using SQL.

Demonstrated SQL Concepts

  • Aggregations: COUNT(), SUM(), AVG(), MIN(), MAX() with GROUP BY.
  • Relational Joins: Multi-table queries utilizing INNER JOIN and LEFT JOIN.
  • Filtering & Slicing: Conditional evaluation using WHERE, HAVING, and pattern matching.
  • Subqueries & CTEs: Modular common table expressions for multi-stage metric calculations.

Sample Query Blueprint

-- Sample analytical aggregation query
SELECT category, COUNT(id) AS total_orders, ROUND(AVG(amount), 2) AS avg_ticket
FROM transactions
GROUP BY category
HAVING total_orders > 50
ORDER BY avg_ticket DESC;
